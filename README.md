# Zero releases

Installers for [Zero](https://zeroplatform.app), a desktop workspace for working
on a project together with an AI model.

- **Download:** the [latest release](https://github.com/wellloy1/zero-releases/releases/latest), or the [download page](https://zeroplatform.app/download)
- **Documentation:** https://zeroplatform.app/docs
- **Changelog:** https://zeroplatform.app/changelog

This repository holds released installers only. It contains no source code.
